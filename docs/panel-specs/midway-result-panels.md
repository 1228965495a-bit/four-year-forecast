# 中途结算页 面板美术规格（2 张）

页面：`/midway-result`
渲染方式：CSS `border-image`（9-slice），四角固定像素、四边和中心区域会被拉伸/平铺填充。
所以画的时候要把「装饰细节」放在四角/顶部标题带里，中间大片区域尽量做成**可无缝纵向/横向重复**的纯色或规则条纹。

---

## 通用要求（两张都适用）

- 格式：PNG，透明背景（`RGBA`），无抗锯齿柔边（纯像素风，硬边缘）。
- 画布：**512 × 512 px**（正方形），像素单位 1:1，不要缩放导出。
- 9-slice inset：**上/下/左/右各 60 px**。也就是：
  - 四角保护区：`60 × 60 px`，四角的装饰必须完整落在这个方块内，不能超出。
  - 中间可拉伸区域：宽/高 `512 - 60*2 = 392 px`。
  - 中间区域**必须是可以横向和纵向无缝重复**的纹理（推荐纯色或水平/垂直条纹），否则拉伸会出现明显接缝。
- 描边：外描边 1~2 px 深色，保证在任意尺寸下轮廓清晰。
- 交付时同时给一张 `annotated.png`，用红线标出上下左右各 60 px 的 slice 分隔线，方便验收。

参考 slice 示意（数字为像素）：

```text
┌──60──┬──────392──────┬──60──┐
│ 角   │   顶边(可拉伸) │ 角   │ 60
├──────┼───────────────┼──────┤
│      │               │      │
│ 左边 │  中心(可拉伸  │ 右边 │ 392
│(可拉)│   +可平铺)    │(可拉)│
│      │               │      │
├──────┼───────────────┼──────┤
│ 角   │   底边(可拉伸) │ 角   │ 60
└──────┴───────────────┴──────┘
```

## Panel 1：`diagnosis`（中途报告 / 绿色卷边纸）

- 用途：中途结算页顶部「中途报告」结论卡片。
- 现状问题：源图 248×351，比例窄，被强行拉宽后顶部绿色卷边和挂扣变形。
- 视觉方向：米黄色羊皮纸底 + 顶部深绿色横幅（带金属挂扣/铆钉装饰），横幅只出现在顶部 60px 内。
- 具体要求：
  - 顶部 0–60px：绿色横幅装饰带，左右两端各画一个金属挂扣/铆钉，铆钉必须落在左右各 60px 的角区内。中间横幅本体（392px 宽区域）**做成可横向重复的纯绿色条纹**，不要在中间画独有的图案。
  - 中部 60–452px：米黄色羊皮纸底色（可带极轻微的横向纹理，但必须能纵向无缝重复）。
  - 底部 452–512px：与左右边一致的纸张边缘，可加一条深色阴影线。
  - 左右边 0–60 / 452–512：纸张竖向纹理，能纵向重复。
- 落地 CSS：`border-width: 26px`（源 60px → 屏幕 26px），padding 由页面控制。

## Panel 2：`noteYellow`（来自未来的你 / 黄色便签）

- 用途：中途结算页 / 毕业结算页底部「来自未来的你」便签。
- 现状问题：源图非正方形 + inset 太大，被拉伸后左上图钉和右下信封图标位置漂移。
- 视觉方向：奶油黄色便签纸，左上角一枚粉色图钉，右下角一枚信封小图标，四周有轻微卷边阴影。
- 具体要求：
  - 左上角 0–60 / 0–60：**粉色图钉完整画在这个 60×60 方块内**，不要超出。
  - 右下角 452–512 / 452–512：**信封小图标完整画在这个 60×60 方块内**。
  - 其余三个角（右上、左下）：只画纸张卷边阴影，不要放独有图案。
  - 中部 60–452：奶油黄色纯色（或极淡的横向纸纹，必须能双向无缝重复）。**不要在中间画装饰、字、心形、下划线等**，否则拉伸会重复出现。
  - 上下左右边（角之间的条状区）：只放能沿该方向重复的纸张边缘阴影。
- 落地 CSS：`border-width: 18px`（源 60px → 屏幕约 18px），padding 由页面控制。
